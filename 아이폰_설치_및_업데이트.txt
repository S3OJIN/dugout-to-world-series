덕아웃에서 월시까지 — 아이폰 웹 앱 패키지

설치하려면 이 폴더의 파일을 모두 HTTPS 정적 웹 호스팅에 올려야 합니다.
index.html, manifest.webmanifest, sw.js, 아이콘 파일이 같은 폴더 경로에 있어야 합니다.

아이폰 설치
1. Safari로 배포된 HTTPS 주소를 엽니다.
2. 공유 버튼 → 홈 화면에 추가를 선택합니다.
3. ‘웹 앱으로 열기’를 켜고 추가합니다.
4. 최초 한 번은 온라인 상태에서 게임을 열어 오프라인 캐시를 받습니다.

패치와 업데이트
Codex가 수정하는 원본 HTML만 바꾸면 이미 배포된 앱에는 자동으로 반영되지 않습니다.
수정한 index.html을 같은 웹 주소에 다시 배포하면, 앱을 온라인 상태에서 다시 열 때 최신 게임 파일을 받아옵니다.
서비스 워커는 오프라인에서도 마지막으로 받아 둔 게임을 열도록 구성되어 있습니다.

이 패키지는 설치 준비가 된 정적 웹 앱입니다. 아직 공개 HTTPS 주소에 배포되지는 않았습니다.
